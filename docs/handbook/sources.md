# Official sources behind the contributor handbook

Checked 2026-09-20. These references inform writing/tool behavior, not proof that
Big passed a release gate. The manifests, source and tests define the local build.
Recheck the relevant upstream version when changing an API or command.

- [GitHub: README purpose and relative links](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes)
- [GitHub: contributor guidelines](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/setting-guidelines-for-repository-contributors)
- [AGENTS.md format](https://agents.md/) and [Codex discovery](https://developers.openai.com/codex/guides/agents-md)
- [Claude Code instruction discovery](https://code.claude.com/docs/en/memory#agentsmd) and [Copilot instructions](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/add-custom-instructions/add-repository-instructions)
- [Cargo workspaces](https://doc.rust-lang.org/cargo/reference/workspaces.html) and [root dependency overrides](https://doc.rust-lang.org/cargo/reference/overriding-dependencies.html)
- [Rust API documentation guidelines](https://rust-lang.github.io/api-guidelines/documentation.html)
- [GNOME interface guidelines](https://developer.gnome.org/hig/guidelines.html) and [GTK threading](https://docs.gtk.org/gtk4/section-threading.html)
- [GitHub Actions security](https://docs.github.com/en/actions/reference/security/secure-use)

Big's handbook separates onboarding, task recipes, API reference, mandatory
contracts, proposed roadmap and dated evidence. This is a project editorial choice,
not a claim that these upstream projects prescribe Big's architecture.
